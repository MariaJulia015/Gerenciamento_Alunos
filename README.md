# EC01 - Gerenciamento de Alunos (DevTech Academy)

Sistema em HTML e JavaScript para cadastrar, listar, editar e excluir alunos, com relatórios.

- **Exercício 1:** formulário (nome, idade, curso, nota final) e tabela com botões Editar/Excluir; dados em array de objetos.
- **Exercício 2:** classe `Aluno` com construtor, `isAprovado()` e `toString()`.
- **Exercício 3:** `addEventListener`, funções anônimas, arrow functions e mensagens com `alert()`/`console.log()`.
- **Exercício 4:** relatórios com `filter`, `map`, `reduce`, `sort` e `forEach`.

## Como rodar com Docker

```bash
docker compose up --build
```

Acesse http://localhost:8080
